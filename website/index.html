terminal — quick start
$ curl -fsSL https://github.com/Arab-Open-Source/Altair/releases/latest/download/install.sh | sh # verifies SHA-256, installs to ~/.local/bin $ altair --version Altair 0.3.x
$ altair new blog $ cd blog && shards install $ altair g scaffold Post title:string body:text # model + migration + controller + views + routes
$ altair db:migrate && altair server Listening on http://localhost:3000 # open http://localhost:3000 — posts persist across restarts

One framework, the whole stack

Everything a web app needs ships together and agrees on conventions — typed at compile time, so renames break the build instead of the page.

Record — a real ORM

SQLite3 and PostgreSQL adapters, migrations with db/schema.cr, validations, callbacks, associations with batched eager loading, and a contract suite that runs against both backends.

Read the ORM guide

Segment-based routing

Typed to: PagesController.index references, resources, constraints, globs and redirects.

Controllers

Per-request instances, typed params, filters, callbacks and content negotiation.

Views

Compile-time ECR with auto-escaping, layouts, partials and a form builder.

Sessions and auth

Signed cookies, flash, CSRF and full registration via altair g auth.

Secure by default

Security headers, request ids, sliding-window rate limiting and opt-in CORS.

CLI + generators

new, g scaffold, server, routes and database commands.

Performance

Measured under real load

A public k6 harness compares Altair with Express, Fiber and a Ruby full-stack MVC app on identical PostgreSQL-backed CRUD endpoints — 100 virtual users for 60 seconds at an identical connection budget.

Altair

Write · POST /items

13,981 req/s

1.7x Express · 6.3x the Ruby full-stack arm · best write max of all four (25.2 ms, tighter than Go).

Altair

Read · GET /items/:id

13,619 req/s

1.8x Express · 4.6x the Ruby full-stack arm · deterministic tail on the official gcry collector.
