Highlights

18.1 ms
Best write max of all four arms — and the tightest p99.9 (10.7 ms), below even Go.
6.7×
Faster writes than the Ruby full-stack arm — the closest architectural peer (4.4× on reads).
1.7×
Faster than Express on writes, 1.6× on reads — with a 3x tighter write p99.
  • Fiber (Go) leads raw throughput; Altair holds second place with a statistically tied write p99 (8.6 vs 8.5 ms).
  • Zero meaningful failures across all eight runs (17 warmup-boundary resets on Express, 2 on Ruby).
  • Altair's read tail carries one Boehm stop-the-world GC pause — the tracked next optimization target.
